# Как самостоятельно менять сайт THE | WESHALKA

Админ-панель: **https://theweshalka.ru/admin/**
Все изменения появляются на сайте примерно через 1–2 минуты после нажатия «Сохранить».

## 1. Первый вход (один раз)

Сайт хранится в вашем аккаунте GitHub **WESHALKA12** (почта Butikweshalka@yandex.ru).

1. Войдите на https://github.com под аккаунтом WESHALKA12.
2. Откройте https://github.com/settings/personal-access-tokens/new
3. Заполните:
   - **Token name**: `Админка сайта`
   - **Expiration**: `No expiration` (или 1 год — тогда через год повторите шаги);
   - **Repository access**: `Only select repositories` → выберите `weshalka12.github.io`;
   - **Permissions → Repository permissions → Contents**: `Read and write`.
4. Нажмите **Generate token** и скопируйте длинный код (показывается один раз).
5. Откройте https://theweshalka.ru/admin/ → **«Войти с помощью токена доступа»** → вставьте код.

Браузер запомнит вход. Никому не пересылайте этот код. Если код утёк — удалите его на странице
https://github.com/settings/personal-access-tokens и создайте новый.

> Кнопку «Войти через GitHub» не используйте — она требует отдельного платного/серверного
> подключения. Вход выполняется только по коду (п. 5).

## 2. Товары — «Каталог → Товары»

Каждая строка — одна карточка на сайте. **Порядок в списке = порядок на сайте**:
перетаскивайте карточку за значок `=`.

- **Добавить товар** — кнопка сверху. Обязательно заполните: адрес страницы (латиницей, например
  `trench-beige`), название, разделы каталога, категорию и хотя бы один цвет с фото.
- **Скрыть** — включите «Скрыть с сайта» (товар останется в админке).
- **Удалить** — крестик `×` справа на карточке, затем «Сохранить».
- **Цена** — общая цена товара; у отдельного цвета можно указать свою. Старая цена — зачёркнутая.
- **Разделы каталога** — Классика, Приталенные, Пальто-халаты, Пальто со стойкой, Пальто-пиджаки,
  **Высокий рост 170+**, Зимние, Экошубы, Тренчи.
- **Бейдж** — «НОВИНКА», «ЭКСКЛЮЗИВ», «ХИТ ПРОДАЖ», «СКИДКА».

### Цвета, фото и видео
Одна модель в нескольких цветах — это **одна карточка**, внутри «Цвета» добавьте нужные цвета.
У каждого цвета:
- **Фотографии** — «Обзор» или перетащите файлы. **Первое фото — главное.** Порядок меняется
  перетаскиванием за значок `⋮⋮`.
- **Видео** — файл MP4 (по желанию, желательно до 20 МБ).
- **В наличии** — выключите, если цвет закончился: на сайте появится «Нет в наличии»,
  кнопка корзины станет неактивной.
- **Размеры** — каждый размер отдельным пунктом (или через запятую).
- Код цвета (black, burgundy, brown, chocolate, graphite, grey, nude, beige, cream, milk, white)
  задаёт цвет кружка-переключателя.

## 3. Главная, контакты, акции, отзывы — «Страницы и контакты»

- **Контакты** — Telegram, MAX, ВКонтакте, WhatsApp, адрес, режим работы, «Как нас найти».
  В поле **«MAX — ссылка на ваш профиль»** вставьте ссылку из приложения MAX (Профиль → Поделиться).
  Пока поле пустое, кнопка MAX на сайте копирует номер телефона.
- **Главная страница** — тексты всех блоков, видео блока 170+ и «Стойка», фото блока «Экошубы»,
  избранные модели.
- **Акции** — «Добавить акцию»: заголовок, текст, фото, ссылка. Если акций нет — показывается
  текст-заглушка.
- **Отзывы** — публикуйте только настоящие отзывы покупателей. Пока отзывов нет, блок на главной
  скрыт.

## 4. Если что-то пошло не так

Каждое сохранение — это версия в истории GitHub, её можно вернуть:
https://github.com/WESHALKA12/weshalka12.github.io/commits/main
После каждого сохранения автоматически запускается проверка данных (вкладка **Actions** в GitHub):
красный значок означает ошибку (например, у цвета нет фото) — текст ошибки на русском.
